<h1>Study-Java</h1>
<p>Repository with codes to learn about some Java concepts<br>

<h2>Modules</h2>

| Folder | Description | Build |
|---|---|---|
| `fundamentos` | Java fundamentals, JDBC, JSP/Servlet and design patterns examples | Eclipse project |
| `bankline-api` | Bank statement REST API with Spring Boot | Maven module |
| `cloud-parking` | Parking management REST API with Spring Boot | Maven module |
| `digital-gym` | Gym management REST API with Spring Boot | Maven module |
| `digital-bank` | Bank account management with OOP | Plain Java |
| `bootcamp-poo` | OOP bootcamp challenge | IntelliJ project |

<h2>How to Run</h2>
<p>Build all Maven modules from the root with <code>mvn clean install</code>, or open a single folder in your favourite IDE.<br>
